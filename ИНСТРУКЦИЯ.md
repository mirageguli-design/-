# 🚀 Инструкция по использованию

## Быстрый старт

1. **Откройте `test.html`** в браузере для просмотра тестовой страницы
2. **Откройте `index.html`** в браузере для просмотра основного сайта
3. **Все готово!** Сайт полностью функционален


## 🎯 Использование

### Главная страница
- **Поиск**: Введите название вина в поле поиска
- **Фильтры**: Выберите страну, сорт винограда, тип сладости
- **Карточки вин**: Кликните на карточку вина для просмотра детальной информации
- **Навигация**: Используйте навигационное меню для перехода между секциями

### Детальная информация
- Откроется модальное окно с полной информацией о вине
- Можно закрыть окно, кликнув на крестик или нажав ESC
- Информация включает: цвет, аромат, вкус, гастрономические сочетания

## 🚀 Деплой на хостинг

1. Загрузите все файлы на хостинг
2. Убедитесь, что все файлы находятся в одной папке
3. Откройте `index.html` в браузере
4. Готово!

### Важно при деплое
- Все файлы должны находиться в одной папке
- `wines.json` должен быть доступен для загрузки
- Изображения вин должны быть в той же папке
- Убедитесь, что хостинг поддерживает загрузку JSON файлов

## 🐛 Решение проблем

### Изображения не загружаются
- Убедитесь, что изображения находятся в той же папке, что и `index.html`
- Проверьте названия файлов в `wines.json`
- Если изображение не загрузится, будет показано fallback изображение

### Данные не загружаются
- Убедитесь, что `wines.json` находится в той же папке, что и `index.html`
- Проверьте, что хостинг поддерживает загрузку JSON файлов
- Откройте консоль браузера для просмотра ошибок

### Анимации не работают
- Убедитесь, что интернет соединение активно (GSAP загружается из CDN)
- Проверьте, что JavaScript включен в браузере
- Откройте консоль браузера для просмотра ошибок

## 📞 Поддержка
