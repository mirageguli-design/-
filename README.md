# 🍷 Винная Коллекция

Информативный сайт для изучения белых вин со всего мира с современным 3D минималистичным дизайном и плавными анимациями.

## ✨ Особенности

- **27 белых вин** из разных стран мира
- **Поиск и фильтрация** по названию, стране, сорту винограда, типу сладости
- **3D эффекты** при наведении на карточки вин
- **Плавные анимации** с использованием GSAP
- **Детальная информация** о каждом вине
- **Адаптивный дизайн** для всех устройств
- **Минималистичный современный дизайн**

## 🚀 Технологии

- **HTML5** - структура сайта
- **CSS3** - стили, 3D эффекты, анимации
- **JavaScript (Vanilla)** - функциональность
- **GSAP** - плавные анимации и эффекты
- **JSON** - данные о винах

## 📁 Структура проекта

```
.
├── index.html          # Главная страница
├── styles.css          # Стили и анимации
├── script.js           # JavaScript логика
├── wines.json          # Данные о винах
├── test.html           # Тестовая страница
├── README.md           # Документация
└── photo_*.jpg         # Изображения вин
```

## 🎯 Использование

1. Откройте `index.html` в браузере
2. Используйте поиск для поиска вин по названию
3. Фильтруйте вина по странам, сортам винограда, типам сладости
4. Кликните на карточку вина для просмотра детальной информации
5. Наслаждайтесь плавными анимациями и 3D эффектами!

## 🎨 Анимации и эффекты

- **Параллакс эффекты** в hero секции

- **Анимация навигации** при прокрутке

## 📝 Деплой

Все файлы готовы к деплою на любой хостинг:

1. Загрузите все файлы на хостинг
2. Убедитесь, что `wines.json` находится в той же папке, что и `index.html`
3. Убедитесь, что изображения вин находятся в той же папке
4. Откройте сайт в браузере
